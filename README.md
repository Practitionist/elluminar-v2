# Elluminar v2

Clean-Sheet Hexagonal Architecture Monolith (`Next.js 16.4` + `Hono RPC` + `Prisma PG Driver Adapter` + `True Double-Entry Ledger` + `India B2B GST SAC 999293` + `Pluggable Multimodal Work Artifacts`).

## Workspace Commands

```bash
pnpm db:generate   # Generate Prisma Client into packages/db/src/generated/prisma
pnpm typecheck     # Run full monorepo TypeScript verification across all packages & apps
pnpm test          # Run Vitest unit & integration test suites across all packages & apps
pnpm build         # Run full production Next.js 16.4 + Turborepo build
```
